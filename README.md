# 📚 Flashcards App

An interactive flashcards application built with **Vite, React, TypeScript and Tailwind CSS**. This app helps users improve their learning by creating, organizing, and reviewing flashcards efficiently.

---

## 🚀 Features

- 📖 **Create & Edit Flashcards** – Add, edit, and delete flashcards easily.
- 🔄 **Review Mode** – Flip cards to test knowledge.
- 🏷️ **Categories & Tags** – Organize flashcards into different subjects.
- 🌙 **Dark Mode Support** – Switch between light and dark themes.
- ⚡ **Fast & Optimized** – Built with Vite for lightning-fast performance.
- 🏗️ **Responsive UI** – Fully optimized for mobile & desktop.

---

## 🛠️ Tech Stack

- **Vite** – Fast development and optimized builds.
- **React + TypeScript** – Strongly-typed, scalable front-end framework.
- **Tailwind CSS** – Modern utility-based styling.

---
